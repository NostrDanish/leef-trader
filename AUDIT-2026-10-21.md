## Code Red-Flag Review (new code, PR #40)
- AI execution seam (`ai-executor.ts` + control seam in `use-bot-loop.ts`): pure question builder/parser; execution gated by freshness (≤120 s), confidence floor (0.75, weakest judgment), risk nouls (`riskExecute` < 0.5 blocks all actions; `riskStress` > 0.5 vetoes entries but never exits), closed token sets, and the full unchanged gauntlet. Engine sells/stops bypass the seam — AI cannot suppress risk exits. Verified sound.
- `ai-exec-panel.tsx`: CONTROL gated behind an explicit AlertDialog; store double-checks and can refuse. One-click "Apply via Swap desk" routes through the manual swap path's own gates.
- Policy firewall (`policy.ts`): allowlisted AMM receivers, receiver pinned to signer, contract+precision verified against token catalog, zero-min-out memos rejected, 3% slippage hard cap, owner permission refused, fee recipient is a compile-time constant. Unchanged and solid.
- `api/jev.ts`: no logging of bodies/answers, key never leaves the function, fails closed when unconfigured — but see LT-2 (no abuse throttle).
- No eval/exec of remote input; no new remote code loading.
